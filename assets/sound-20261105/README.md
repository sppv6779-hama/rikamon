# 音タイプ追加 2026-11-05

GAS側はindex.htmlの内容を既存HTMLファイルへ置き換えてデプロイを更新。Code.gs変更不要。

タイプ末尾に音を追加。出題は距離・時間・音速・雷までの距離・反響の壁までの距離・反響の往復時間・反響からの音速の7種類。問題ごとに音速を明示。反響は同じ場所に戻る条件で往復を扱う。雷は光の到達時間を無視する条件を明示。

11体: 幼年期・成長期各1、成熟期・完全体・究極体各3。既存の分岐条件・4問正解で進化する仕組みを利用。既存セーブキーと保存形式を維持。図鑑は合計100体。音アイコンはインラインSVG。

252通りの数値条件を問題文の数値から独立に計算して検証。既存8タイプ200問を同じ乱数条件で比較。旧モンスターデータ・説明・画像URL一致、音タイプの回答・誤答・ヒント・進化先・図鑑・保存復元も確認。検証はNode VMとDOM代替実装を利用。実ブラウザーの画面確認は未実施。

専用画像は組み込みimage_genで生成。プロンプトはart-prompts.json、配信用透過PNGはweb/、高解像度原画はoriginals/。HTMLに画像データは埋め込まずGitHub Pagesから取得する。
